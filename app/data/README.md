# Dados do portfólio

[projects.js](projects.js) reúne títulos, resumos, tecnologias e dados usados nos cartões do catálogo e nas páginas dos projetos. Descreva o contexto profissional de forma genérica e use dados fictícios nas demonstrações.

Valide as alterações com `npm run lint` e `npm run build` e confira o [catálogo e os estudos de caso](../projetos/README.md).
